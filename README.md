# Electricity Lab

Interactive simulations for the Class 10 Science chapter **Electricity**, rebuilt with a modern interface.

| Simulation | What it shows |
|---|---|
| Ohm's Law | How voltage and resistance set the current (V = IR) |
| Resistance in a Wire | How length, area and resistivity set resistance (R = ρL/A) |
| Circuit Kit: AC & DC | Bulbs in series and parallel, with a battery or AC supply |
| Virtual Lab | The Ohm's law experiment: record readings, plot the V–I graph, find an unknown resistance |

The whole site is one file, `index.html`. Open it in a browser, or enable GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
